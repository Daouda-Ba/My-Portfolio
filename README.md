## À compléter

- Ajouter le CV PDF dans `assets/docs/Daouda_Ba_CV.pdf`.
- Ajouter les screenshots réels des projets dans `assets/images/projects/`.
- Ajouter uniquement les liens de démo réellement disponibles.

## Développement local

Le portfolio est un site statique. Il peut être ouvert directement avec `index.html` ou servi localement :

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.
